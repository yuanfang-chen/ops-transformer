## 四、非连续 Tensor 支持判定方式（详细调研）

### 4.1 判定方法总结

| 判定依据 | 说明 | 示例代码 |
|----------|------|----------|
| **代码有 `IsContiguous()` 检查且报错** | 不支持非连续 | `OP_CHECK(IsContiguous(x), ...)` |
| **代码有 `notContiguous` 变量 + 内部转换** | 支持非连续（内部处理） | `if (notContiguous) { TransTensor(x); }` |
| **代码有 `IsTransposeLastTwoDims()` 判断** | 仅支持最后两轴转置的非连续 | `bool notContiguous = IsTransposeLastTwoDims(x2);` |
| **代码有 `l0op::Contiguous` 调用** | 支持非连续（内部自动转换） | `tensor = l0op::Contiguous(tensor, executor);` |
| **`_def.cpp` 中有 `.AutoContiguous()` 声明** | 支持非连续（框架自动转换） | `this->Input("x_ref").AutoContiguous();` |
| **代码无任何 contiguous 相关处理** | 默认不支持 | - |
| **平台判断 `GetCurNpuArch() == DAV_3510`** | 仅 Ascend 950PR/950DT 支持 | `if (notContiguous && GetCurNpuArch() == NpuArch::DAV_3510)` |

### 4.2 关键代码模式识别

#### 模式 1：不支持非连续 Tensor
```cpp
// 直接报错，要求必须是连续的
OP_CHECK(IsContiguous(x), OP_LOGE(..., "only support x tensor is contiguous."), return error);
```

#### 模式 2：仅支持转置非连续（常见于 weight 矩阵）
```cpp
// 判断是否为最后两轴转置的非连续
bool notContiguous = IsTransposeLastTwoDims(x2);

// 同时设置转置标志和非连续会报错
if (notContiguous && transposeX2) {
    OP_LOGE(..., "x2 not contiguous, and set x2 transpose, it is error!");
    return ACLNN_ERR_PARAM_INVALID;
}

// 仅在 DAV_3510 平台处理非连续
if (notContiguous && GetCurrentPlatformInfo().GetCurNpuArch() == NpuArch::DAV_3510) {
    transposeX2 = !transposeX2;
    auto transX2 = TransX2Tensor(x2);  // 内部转换处理
}
```

#### 模式 3：内部转换为连续（支持非连续）
```cpp
// 使用 l0op::Contiguous 进行内部转换
const aclTensor *contiguousTensor = l0op::Contiguous(tensor, executor);
```

#### 模式 4：框架自动转换（支持非连续）
```cpp
// 在 op_host/*_def.cpp 中声明，表示框架会自动将非连续 Tensor 转换为连续
this->Input("x_ref")
    .ParamType(REQUIRED)
    .DataType({ge::DT_BF16, ge::DT_FLOAT16, ...})
    .FormatList({ge::FORMAT_ND})
    .AutoContiguous();  // 支持非连续 Tensor
```

### 4.5 平台差异说明

部分算子的非连续支持与 NPU 架构相关：
- **DAV_3510** (Ascend 950PR/Ascend 950DT): 可能支持特定场景的非连续
- **其他架构** (Atlas A2/A3): 通常不支持非连续

代码判断方式：
```cpp
if (GetCurrentPlatformInfo().GetCurNpuArch() == NpuArch::DAV_3510) {
    // 支持/处理非连续
}
```

**文档填写建议**：
- 如果代码中包含 `DAV_3510` 判断，建议在文档中注明平台差异
- 如果仅 DAV_3510 支持，填写 `√（仅Ascend 950PR/950DT）`

## 九、补充调研：gmm 目录 AutoContiguous 用法

### 9.1 gmm 目录结构

`gmm/` 目录包含独立的 grouped_matmul 系列算子实现，与 `mc2/` 目录下的算子相互独立：
- `grouped_matmul/` - 基础分组矩阵乘法
- `grouped_matmul_add/` - 分组矩阵乘法加法融合
- `grouped_matmul_finalize_routing/` - 路由终态化
- `grouped_matmul_swiglu_quant/` - 量化 SwiGLU 融合
- `quant_grouped_matmul_dequant/` - 量化反量化
- `quant_grouped_matmul_inplace_add/` - 原地加法

### 9.2 AutoContiguous 使用示例

`gmm/grouped_matmul_add/op_host/grouped_matmul_add_def.cpp` (L26-43):
```cpp
this->Input("x")
    .ParamType(REQUIRED)
    .DataType({ge::DT_BF16, ge::DT_FLOAT16})
    .Format({ge::FORMAT_ND, ge::FORMAT_ND})
    .AutoContiguous();    // x 支持非连续
this->Input("weight")
    .ParamType(REQUIRED)
    .DataType({ge::DT_BF16, ge::DT_FLOAT16})
    .Format({ge::FORMAT_ND, ge::FORMAT_ND})
    .AutoContiguous();    // weight 支持非连续
this->Input("group_list")
    .ParamType(REQUIRED)
    .DataType({ge::DT_INT64, ge::DT_INT64})
    .Format({ge::FORMAT_ND, ge::FORMAT_ND})
    .AutoContiguous();    // group_list 支持非连续
```

对应的 op_api 实现 (`aclnn_grouped_matmul_add.cpp` L101-115):
```cpp
static aclnnStatus DataContiguous(const aclTensor *&tensor, aclOpExecutor *executor) {
    tensor = l0op::Contiguous(tensor, executor);
    return ACLNN_SUCCESS;
}

static aclnnStatus ParamsDataContiguous(gmm_add_advanced::GroupedMatmulAddParams &params, aclOpExecutor *executorPtr) {
    CHECK_COND(DataContiguous(params.x, executorPtr) == ACLNN_SUCCESS, ...);
    CHECK_COND(DataContiguous(params.weight, executorPtr) == ACLNN_SUCCESS, ...);
    CHECK_COND(DataContiguous(params.groupList, executorPtr) == ACLNN_SUCCESS, ...);
    ...
}
```

### 9.3 gmm 目录非连续支持情况

| 算子 | 非连续支持方式 | 代码位置 |
|------|---------------|----------|
| grouped_matmul_add | `AutoContiguous` + `l0op::Contiguous` | `_def.cpp:31,37,43` + `aclnn_*.cpp:101-115` |
| quant_grouped_matmul_dequant | `IsContiguous` 检查（weight/out 必须连续） | `aclnn_*.cpp:209` |
