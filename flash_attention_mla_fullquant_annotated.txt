1.2 Flash Attention计算流程
--------------------------------------------------------------------------------

    输入: Q (Query), K (Key), V (Value)
    
    ┌───────────────────────────────────────────────────────────────────┐
    │                                                               │
    │  Step 1: BMM1 (Cube引擎)                                      │
    │  ┌─────────────────┐                                         │
    │  │  Q [B,N1,S1,D]  │                                         │
    │  │       ×          │                                         │
    │  │  K [B,N2,S2,D]  │                                         │
    │  │       ↓          │                                         │
    │  │  S [B,N1,S1,S2] │  (注意力分数矩阵)                       │
    │  └─────────────────┘                                         │
    │                                                               │
    │  Step 2: Vec1 (Vector引擎) - Softmax                          │
    │  ┌─────────────────┐                                         │
    │  │  S [B,N1,S1,S2] │  ──►  P = softmax(S)  (行归一化)     │
    │  │       ↓          │                                         │
    │  │  P [B,N1,S1,S2] │                                         │
    │  └─────────────────┘                                         │
    │                                                               │
    │  Step 3: BMM2 (Cube引擎)                                      │
    │  ┌─────────────────┐                                         │
    │  │  P [B,N1,S1,S2] │                                         │
    │  │       ×          │                                         │
    │  │  V [B,N2,S2,Dv] │                                         │
    │  │       ↓          │                                         │
    │  │  O [B,N1,S1,Dv] │  (输出)                                │
    │  └─────────────────┘                                         │
    │                                                               │
    │  Step 4: Vec2 (Vector引擎) - 后量化                           │
    │  ┌─────────────────┐                                         │
    │  │  O [B,N1,S1,Dv] │  ──►  int8/uint8 (量化输出)          │
    │  └─────────────────┘                                         │
    │                                                               │
    └───────────────────────────────────────────────────────────────────┘

1.3 MLA (Multi-Latent Attention) 特殊处理
--------------------------------------------------------------------------------

    MLA使用低秩分解来减少KV缓存:
    - 标准的KV: [B, N, S, D]
    - MLA的KV: 分解为Nope + Rope两部分
    
    ┌─────────────────────────────────────────────────────────────┐
    │                 MLA分解示意图                              │
    │                                                             │
    │   K_std [B,N,S,D]  ──►  Nope [B,N,S,Dv] + Rope [B,N,S,D-Dv]│
    │                            ↓                  ↓              │
    │                      Q_nope [B,N1,S,Dv]     Q_rope [B,N1,S,D-Dv]│
    │                            ×                  ×              │
    │                          Nope              Rope             │
    │                            │                  │              │
    │                            └────────┬─────────┘              │
    │                                     ↓                       │
    │                              S_final                        │
    └─────────────────────────────────────────────────────────────┘

2.2 InitUniqueConstInfo() - 初始化常量信息
--------------------------------------------------------------------------------

    功能: 从sharedParams复制配置到constInfo
    
    主要配置项:
    ┌─────────────────────────────────────────────────────────────┐
    │ 1. Flash Decode配置 (isFd=true时)                        │
    │    - splitKVNum: KV分块数量                               │
    │    - sInnerLoopSize: 内层循环大小 = ceil(s2Size/splitKVNum)│
    │                                                             │
    │ 2. 后量化配置 (POST_QUANT=true时)                          │
    │    - isPostQuantPerChnl: 是否按通道后量化                   │
    │    - isPostQuantBF16: 输出是否转BF16                       │
    │                                                             │
    │ 3. 注意力通用配置                                          │
    │    - isRowInvalid: 是否有无效行需要mask                     │
    │    - headNumRatio: Q的head数 / KV的head数 (GQA支持)       │
    │    - isGqa: 是否使用Group Query Attention                  │
    │    - isKvContinuous: KV是否连续存储                         │
    │    - actualSeqLenSize/KVSize: 序列长度数组大小              │
    │                                                             │
    │ 4. Page Attention配置 (isPa=true时)                        │
    │    - blockTableDim2: 块表第二维大小                        │
    │    - blockSize: 块大小 (通常128)                          │
    │    - paLayoutType: PA布局类型                             │
    │                                                             │
    │ 5. MLA矩阵维度预计算                                      │
    │    - n2GD = n2G * dSize: N2与D的乘积                     │
    │    - gDR = gSize * dSizeRope: 全局与Rope维度乘积         │
    │    - n2GDR = n2Size * gDR: 综合维度                      │
    └─────────────────────────────────────────────────────────────┘

2.3 ProcessMainLoop() - 主计算循环 (核心)
--------------------------------------------------------------------------------

    整体结构: 三层循环 + 流水线执行
    
    ┌─────────────────────────────────────────────────────────────┐
    │ for (bnIdx = bnStartIdx; bnIdx < bnEndIdx; ++bnIdx) {    │  外层: Batch-N维度
    │     for (gS1Index = gS1StartIdx; gS1Index < tempGS1End│  中层: GS1分块索引
    │         ++gS1Index) {                                   │
    │         for (s2LoopCount = 0; s2LoopCount <= s2LoopLimit│  内层: S2循环计数
    │             ++s2LoopCount) {                             │
    │             // 流水线执行 (双缓冲)                         │
    │         }                                                 │
    │     }                                                     │
    │ }                                                         │
    └─────────────────────────────────────────────────────────────┘

    流水线执行时序:
    
    taskId:   0     1     2     3     4     5     6
    ─────────────────────────────────────────────────────
    BMM1:     ■─────■─────■─────■─────■─────■─────■
               │
    Vec1:          □─────□─────□─────□─────□─────□─────
               │
    BMM2:              ●─────●─────●─────●─────●─────●
               │
    Vec2:                  ○─────○─────○─────○─────○─────○
    
    说明:
    - ■ = BMM1 (Cube引擎): Q × K^T
    - □ = Vec1 (Vector引擎): Softmax归一化
    - ● = BMM2 (Cube引擎): P × V
    - ○ = Vec2 (Vector引擎): 后量化处理
    
    环形缓冲: 使用 runInfo[4] 实现双缓冲，taskId & 3 实现取余

    多核切分:
    ┌─────────────────────────────────────────────────────────────┐
    │ 非Flash Decode模式:                                        │
    │   actualCoreNums = coreNum                               │
    │   切分维度: [batch * n2 * headNumRatio]                  │
    │                                                             │
    │ Flash Decode模式:                                         │
    │   actualCoreNums = bSize * n2Size * splitKVNum           │
    │   切分维度: [batch * N2 * SplitKV]                       │
    └─────────────────────────────────────────────────────────────┘

2.4 Process() - 主入口函数
--------------------------------------------------------------------------------

    执行流程:
    
    ┌─────────────────────────────────────────────────────────────┐
    │  1. SyncAll<false>()                                    │
    │     - 仅在首次调用时执行 (needInit=true)                   │
    │     - 确保多核数据一致性                                   │
    │                                                             │
    │  2. ProcessMainLoop()                                    │
    │     - 执行主要注意力计算流水线                             │
    │                                                             │
    │  3. FlashDecode处理 (isFd=true时)                        │
    │     - SyncAll(): 等待主循环完成                           │
    │     - InitFDBuffers(): 初始化FlashDecode缓冲区            │
    │     - FlashDecodeCompute(): 执行FlashDecode计算          │
    └─────────────────────────────────────────────────────────────┘

3.5 FlashDecodeCompute() - Flash解码计算
--------------------------------------------------------------------------------

    功能: 处理KV Cache的Flash解码，将分块结果合并
    
    计算流程:
    
    ┌─────────────────────────────────────────────────────────────┐
    │ 1. 计算当前AIV核心的batch和n2索引                            │
    │    bIdx = aivIdx / n2Size                                 │
    │    n2Idx = aivIdx % n2Size                               │
    │                                                             │
    │ 2. 获取实际KV序列长度                                       │
    │    - 从actualSeqKvlenAddr读取                             │
    │    - 处理左填充和右填充                                     │
    │                                                             │
    │ 3. 计算合并循环次数                                        │
    │    actualCombineLoopSize = ceil(actualSeqLen / sInnerLoopSize)│
    │                                                             │
    │ 4. 合并SplitKV结果                                        │
    │    CombineSplitKVRes(...)                                 │
    └─────────────────────────────────────────────────────────────┘

3.6 CombineSplitKVRes() - 合并分块KV结果
--------------------------------------------------------------------------------

    功能: 将多个SplitKV分块的结果合并
    
    处理流程:
    
    ┌─────────────────────────────────────────────────────────────┐
    │ 计算G维度切分大小:                                         │
    │   gSplitSize = min(32KB/(splitKVNum*32B), 32KB/sizeof(float))│
    │   gSplitSize = min(gSplitSize, gMax)                       │
    │                                                             │
    │ 循环处理每个G分块:                                          │
    │   for (i = 0; i < loopCount; i++) {                      │
    │       CopyLseIn(...)        // 拷贝LSE到UB                  │
    │       ComputeScaleValue(...) // 计算scale值                 │
    │       ReduceFinalRes(...)   // 归约最终结果               │
    │       CopyFinalResOut(...)  // 拷贝结果到GM               │
    │   }                                                        │
    └─────────────────────────────────────────────────────────────┘

4.3 IterateBmm1MLAFullQuant() - MLA优化的BMM1
--------------------------------------------------------------------------------

    功能: 执行 Q × K^T 计算，包含MLA特有的Nope+Rope分解
    
    计算流程:
    
    ┌─────────────────────────────────────────────────────────────┐
    │ Step 1: 加载左矩阵Q (仅s2LoopCount==0时)                    │
    │   - 从GM加载Nope部分到L1                                  │
    │   - 从GM加载Rope部分到L1                                  │
    │   - 设置MTE2同步事件                                        │
    │                                                             │
    │ Step 2: 加载右矩阵K                                       │
    │   - 从GM/PA加载Nope部分到L1                               │
    │   - 从GM/PA加载Rope部分到L1                               │
    │   - 设置MTE2同步事件                                        │
    │                                                             │
    │ Step 3: 执行Matmul                                        │
    │   - MatmulK: Nope × Nope                                  │
    │   - MatmulFull: Rope × Rope (累加到Nope结果)              │
    │   - 输出到L0C                                              │
    │                                                             │
    │ Step 4: Fixpipe搬运                                       │
    │   - 从L0C搬运到UB                                        │
    │   - 格式转换: ND → NZ                                     │
    └─────────────────────────────────────────────────────────────┘
    
    MLA特有处理:
    ┌─────────────────────────────────────────────────────────────┐
    │ 输入分解:                                                   │
    │   Q = [B, N1, S1, D_v] + [B, N1, S1, D_rope]            │
    │   K = [B, N2, S2, D_v] + [B, N2, S2, D_rope]            │
    │                                                             │
    │ 计算分解:                                                   │
    │   S = Q_nope × K_nope^T + Q_rope × K_rope^T              │
    │           (MatmulK)          (MatmulFull)                    │
    │                                                             │
    │ 内存布局:                                                   │
    │   L1QBuffer = Q_nope + Q_rope (拼接)                      │
    │   L1KBuffer = K_nope + K_rope (拼接)                      │
    └─────────────────────────────────────────────────────────────┘

4.4 IterateBmm2MLAFullQuant() - MLA优化的BMM2
--------------------------------------------------------------------------------

    功能: 执行 P × V 计算
    
    计算流程:
    
    ┌─────────────────────────────────────────────────────────────┐
    │ Step 1: 等待L1A可用                                     │
    │   - inputBuf.Get() 获取L1A                             │
    │   - WaitCrossCore() 跨核同步                             │
    │                                                             │
    │ Step 2: 准备L1B和L0C                                     │
    │   - l1KBuffers.GetReused() 复用K缓冲区                  │
    │   - mmL0CBuffers.Get() 获取L0C                        │
    │                                                             │
    │ Step 3: 执行Matmul                                       │
    │   - MatmulN: P × V                                      │
    │   - 输出到L0C                                              │
    │                                                             │
    │ Step 4: Fixpipe搬运                                       │
    │   - 从L0C搬运到UB或GM                                   │
    │   - bmm2Write2Ub决定输出位置                              │
    └─────────────────────────────────────────────────────────────┘

7.1 MLA矩阵分解
--------------------------------------------------------------------------------
    K_v = Nope (维度: [B, N, S, D_v])
    K_r = Rope (维度: [B, N, S, D - D_v])
    
    S = Q_v × K_v^T + Q_r × K_r^T

7.2 Softmax计算
--------------------------------------------------------------------------------
    P_ij = exp(S_ij - rowMax) / Σ exp(S_ik - rowMax)

7.3 LogSumExp
--------------------------------------------------------------------------------
    LSE_i = log(Σ exp(S_ij - rowMax_i))
    其中 rowMax_i = max_j S_ij

7.4 后量化
--------------------------------------------------------------------------------
    // Per-Tensor
    Y_quant = round(Y_float / scale + offset)
    
    // Per-Channel
    Y_quant[c] = round(Y_float[c] / scale[c] + offset[c])
