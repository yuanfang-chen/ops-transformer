# FlashAttention Sink 公式实现详解

## 完整公式

$$
m = max(sink, max(S))
$$

$$
Attention = \frac{e^{S - m} * V}{\sum e^{S-m} + e^{sink - m}}
$$

## 代码逐部分解析

### 1. 加载最大值

```cpp
LoadAlign<T, MicroAPI::LoadDist::DIST_BRC_B32>(
    vreg_max_brc, maxUbStart + i);
```

**公式对应**：加载 `m` 值
- `vreg_max_brc` = m
- 从 `maxUbStart + i` 位置加载全局最大值

### 2. 加载输入数据

```cpp
LoadAlign(vreg_input_x, srcUb + i * s2BaseSize);
```

**公式对应**：加载 `S` 值
- `vreg_input_x` = S
- 从 `srcUb + i * s2BaseSize` 位置加载注意力分数

### 3. 计算指数（分子部分）

```cpp
ExpSub(vreg_exp, vreg_input_x, vreg_max_brc, preg_ori_src_n);
```

**公式对应**：`e^{S - m}`
- `vreg_exp = exp(vreg_input_x - vreg_max_brc)`
- `vreg_exp = exp(S - m)`
- 这是分子中的指数部分

### 4. 计算分母（第一部分）

```cpp
Reduce<MicroAPI::ReduceType::SUM, float, float, MicroAPI::MaskMergeMode::ZEROING>(
    vreg_exp_sum, vreg_exp, preg_ori_src_n);
```

**公式对应**：`sum e^{S-m}`
- `vreg_exp_sum = sum(vreg_exp)`
- `vreg_exp_sum = sum(exp(S - m))`
- 这是分母的第一部分

### 5. 计算分母（Sink 部分）

```cpp
if (hasSink) {
    ExpSub(vreg_sink_exp, vreg_sink_input, vreg_max_brc, preg_ori_src_n);
    Add(vreg_exp_sum, vreg_exp_sum, vreg_sink_exp, preg_ori_src_n);
}
```

**公式对应**：`+ e^{sink - m}`
- `vreg_sink_exp = exp(vreg_sink_input - vreg_max_brc)`
- `vreg_sink_exp = exp(sink - m)`
- `vreg_exp_sum = vreg_exp_sum + vreg_sink_exp`
- `vreg_exp_sum = sum(exp(S - m)) + exp(sink - m)`
- 这是分母的第二部分，将 sink 的指数结果累加

### 6. 存储分母

```cpp
StoreUnAlign<float, MicroAPI::PostLiteral::POST_MODE_UPDATE>(
    ((__ubuf__ T *&)expSumUb), vreg_exp_sum, ureg_exp_sum, 1);
```

**公式对应**：存储分母结果
- 将 `vreg_exp_sum` 存储到 `expSumUb`
- 这是完整的分母：`sum e^{S-m} + e^{sink - m}`

### 7. MLA FullQuant 处理

```cpp
if constexpr (isMlaFullQuant) {
    Muls(vreg，_exp, vreg_exp, fp8e4m3MaxValue, preg_ori_src_n);
}
```

**公式对应**：量化处理
- `vreg_exp = vreg_exp * fp8e4m3MaxValue`
- 这是 MLA FullQuant 的量化处理，不影响公式逻辑

### 8. Dropout 处理

```cpp
if constexpr (hasDrop == 1) {
    LoadAlign<uint32_t, MicroAPI::PostLiteral::POST_MODE_UPDATE, MicroAPI::MaskDist::DIST_US>(
        preg1, (__ubuf__ uint32_t *&)dropMaskUb, s2BaseSize >> 3);
    
    MaskInterleave<half>(preg3, preg4, preg1, preg2);
    Select(vreg_sel_drop, vreg_exp, vreg_zero, preg3);
    Muls(vreg_exp, vreg_sel_drop, divValue, preg_all);
}
```

**公式对应**：Dropout 处理
- 根据 dropout 掩码选择保留或置零
- `vreg_exp = vreg_exp * divValue`
- 这是 dropout 处理，不影响公式逻辑

## 公式总结

### 分子部分：
$$
e^{S - m} * V$$
- `vreg_exp` 存储了 `e^{S - m}` 部分
- `V` 的乘法在后续阶段完成

### 分母部分：
$$
\sum e^{S-m} + e^{sink - m}$$
- `vreg_exp_sum` 存储了完整的分母
- 通过 `Reduce<SUM>` 和 `Add` 操作实现

### Sink 的作用：
1. **参与 max 计算**：`m = max(sink, max(S))`
2. **参与分母计算**：`sum e^{S-m} + e^{sink - m}`
3. **不参与分子**：分子只有 `e^{S - m} * V`

### 关键特性：
- **数值稳定性**：通过 `ExpSub(vreg_exp, vreg_input_x, vreg_max_brc)` 实现
- **条件执行**：通过 `if (hasSink)` 控制 sink 逻辑
- **类型支持**：支持 float、bfloat16、fp8_e5m2、fp8_e4m3fn、hifloat8 等多种类型
- **性能优化**：使用 SIMD 指令和掩码优化
